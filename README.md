# NSHex

Source of https://nshex.enclavegames.com, deployed with GitHub Pages.

- Site files live in the root of this repo.
- `/counter/` and `/roulette/` are built on every deploy from [NSHex-Counter](https://github.com/EnclaveGames/NSHex-Counter) and [NSHex-Roulette](https://github.com/EnclaveGames/NSHex-Roulette), so don't add those folders here.
- Deploys run on push to `main`, manually, and whenever either app's `main` changes.
