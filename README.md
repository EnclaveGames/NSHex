# NSHex

Source of https://nshex.enclavegames.com, deployed with GitHub Pages.

- Site files live in the root of this repo.
- `/counter/` is built from [EnclaveGames/NSHex-Counter](https://github.com/EnclaveGames/NSHex-Counter) on every deploy, so don't add a `counter` folder here.
- Deploys run on push to `main`, manually, and whenever NSHex-Counter's `main` changes.
